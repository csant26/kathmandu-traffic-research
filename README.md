# kathmandu-traffic-research

## Brief Overview
A research project analysing the traffic congestion in Kathmandu through simulation using SUMO.

## Goals
- Learn SUMO
- Build a digital model of the Koteshwor–Tinkune corridor
- Collect traffic data
- Evaluate traffic management strategies
